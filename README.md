# Simple Rule Based Text Categorization

This example demonstrates how simple rule-based automation can effectively solve problems that might otherwise be over-engineered with complex AI solutions. It categorizes customer support messages using basic keyword matching, highlighting the efficiency and reliability of straightforward logic over AI agents for specific tasks.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
